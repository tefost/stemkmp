# STEM-проєкт: дослідження СМО, варіант 1 (касова зона супермаркету)

## Що це
Імітаційна (етапи 1-2) та аналітична (етап 3) моделі касової зони цілодобового супермаркету.
Мета: знайти, скільки кас відкривати в кожний період доби, щоб покупці чекали не більше 10 хв.

## Встановлення
    pip install numpy pandas matplotlib python-docx pillow

## Порядок запуску
    python stage1_one_channel.py      # етап 1: одна каса, 1 прогін + 100 прогонів + адекватність
    python stage2_multi_channel.py    # етап 2: 5 кас, пошук графіка (~40 с)
    python stage3_analytical.py       # етап 3: формули Ерланга, порівняння з імітацією
    python sensitivity.py             # чутливість до потоку + перевірка мінімальності графіка
    python draw_diagrams.py           # схема СМО, граф станів, блок-схеми
    python build_report.py            # збирає звіт Word

## Файли
- smo_model.py - спільне ядро: класи Customer, Statistics, Supermarket; параметри; багаторазові прогони
- results/ - таблиці (csv), figures/ - рисунки (png)
- Усі параметри (періоди, λ, час обслуговування) змінюються на початку smo_model.py
